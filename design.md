# TikTok Clone Design System

> Locked design system for the TikTok Clone project.
> Generated by Hallmark — Anti-AI-slop design skill.

## Genre

**Atmospheric** — Dark, immersive, video-first interface. Late-night vibes, neon accents, high contrast.

## Animation

### Easings
```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in: cubic-bezier(0.7, 0, 0.84, 0);
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
```

### Durations
```css
--dur-fast: 150ms;
--dur-normal: 250ms;
--dur-slow: 400ms;
--dur-entrance: 600ms;
```

### Microinteractions
- **Tap feedback**: `transform: scale(0.97)` with 150ms ease-out
- **Hover lift**: `transform: translateY(-2px)` with 250ms ease-out
- **Like heart**: Scale animation with spring physics
- **Page transitions**: Fade + slide up with 400ms ease-out
- **Loading skeleton**: Shimmer animation with 1.5s infinite loop

## Component Patterns

### Video Card
- Aspect ratio: 9:16
- Border radius: 0 (full bleed)
- Overlay gradient: bottom-to-top for text readability
- Right action bar: 56px width, 32px icons

### Bottom Navigation
- Height: 56px
- Icon size: 24px
- Create button: 48px with accent gradient
- Glass morphism background

### Feed Item
- Full viewport height
- Double-tap to like with heart animation
- Swipe navigation between videos
- Progress bar at bottom

## Accessibility

- Focus ring: 2px solid with 2px offset
- Minimum touch target: 44x44px
- Color contrast: WCAG AA compliant
- Reduced motion: All animations disabled
- Screen reader: Semantic HTML and ARIA labels
